# Algora

Algora is a tutoring platform that connects learners with tutors, enabling session scheduling, enrollment management, and Google Calendar integration with automatic Google Meet link generation.

---

## Features

- Google OAuth and email/password authentication  
- Tutor and learner session management  
- One-on-one and group session support  
- Google Calendar event creation with attendees  
- Automatic Google Meet link generation  
- Learner enrollment tracking  
- Session creation, update, and deletion workflows  

---

## Tech Stack

- Next.js  
- React  
- PostgreSQL  
- Prisma  
- NextAuth.js  
- Google Calendar API  
- Vercel
